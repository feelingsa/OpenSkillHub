# 页面、状态和验收映射

## 验收约定

- **设计源**：该区域来自 `node/source` SVG，需在登记视口进行视觉比对。
- **共享代码**：由 Node 前端维护，Skill 页面生成器不可覆盖。
- **补充实现**：设计导出未显示，由产品规则和交互测试验收。
- **Skill 可生成内容**：仅允许出现在共享壳层预留内容区，必须遵守 `SkillManifest` 与共享运行时协议。

## 动效责任

| 交互 | 责任模块 | 减少动效时的结果 |
| --- | --- | --- |
| 卡片堆叠、滚轮切换、悬停抬升 | `frontend/motion/skill-deck.ts` | 立即切换焦点与卡片位置 |
| 弹窗打开和关闭 | `frontend/motion/modal.ts` | 立即显示或隐藏，焦点管理不变 |
| 路由、列表和状态进入 | `frontend/motion/transitions.ts` | 直接呈现最终状态 |
| 队列、运行与权限状态变化 | `frontend/motion/status.ts` | 保留文本和 ARIA 通知，不播放装饰动画 |

所有动画以 GSAP 的 `context`/`matchMedia` 生命周期管理；路由卸载时必须 `revert` 或杀掉对应 timeline。只动画 `transform`、`opacity` 或 CSS variables。

具体加载、错误、权限和离线交互定义见 `ui-state-contract.md`；这些是补充实现，不参与设计导出像素比对。
