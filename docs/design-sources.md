## 视觉验收范围

“1:1 还原”只表示在登记的基准视口中，对 SVG 明确呈现的 Hub 壳层、导航、卡片、表格、筛选、抽屉、确认弹窗及其文案层级、色彩、间距、边框、圆角、阴影和图标进行视觉比对。

以下内容不以像素比对作为验收条件，必须作为产品补充状态实现并有独立交互测试：

- SVG 未呈现的页面、组件变体和原型连接。
- 登录、加载、空数据、错误、无权限、生成中和离线状态。
- 移动端布局和触摸交互（不属于本期实现或验收范围）。
- Skill 专属参数、工作流说明和产物预览区。

## 使用规则

- 共享壳层只能使用 `frontend/styles/tokens.css` 中的令牌，不复制字面色值。
- 生成 Skill 页面只能使用 CSS 自定义属性，不能内联一套独立主题。
- SVG 内嵌 PNG 及路径资源不得复制进提示词或打包到客户端，除非管理员明确审核其版权和用途。
- 视觉比对允许浏览器文字栅格化和动态数据造成的已登记差异；阈值、遮罩和截图命名规则由浏览器测试在 M2 前固化。

## 动效基线

- 依赖在 `package.json` 中固定为 `gsap@3.13.0`，使用 npm 包而非 CDN；许可证为 GSAP 标准许可证，许可证文本随 npm 依赖审计记录。
- 所有模块使用 `gsap.context()` 或 `gsap.matchMedia()` 管理生命周期；路由/组件卸载时调用 `revert()`，手工创建的 tween/timeline 必须保存引用并 `kill()`。
- 使用 `x`、`y`、`scale`、`rotation`、`autoAlpha` 和 CSS variables，不用 GSAP 持续驱动 `width`、`height`、`top` 或 `left`。
- `prefers-reduced-motion: reduce` 时跳过装饰性 timeline 或设为零时长，业务状态与焦点管理保持不变。
